One-line description

Tagline Send files between any device. Instantly.

Short description (≈30 words)

Short blurb OpenDrop is a free, cross-platform AirDrop alternative. Send files between iPhone, Android, PC, and Linux over Wi-Fi or the internet, end-to-end encrypted. With Pro, two phones can also send over Bluetooth when there is no Wi-Fi.

Long description (≈80 words)

Long blurb OpenDrop is a cross-platform file-transfer system. Once paired, the mobile and desktop apps find each other on the same Wi-Fi using multicast DNS. When they're apart, they connect directly peer-to-peer or stream through OpenDrop's own encrypted relay (a shared relay on Free, a faster Pro relay with automatic backup on Pro). With Pro, two phones can also use Bluetooth LE when there is no shared network. File contents are end-to-end encrypted on the sending device with ChaCha20-Poly1305. Relays carry them only in encrypted form, though they can see file names, folder names, sizes and device names. On Pro, OpenDrop's account service stores the shared secret so your devices can sync. There are no ads, no third-party analytics SDKs in the apps, and the business is funded by an optional OpenDrop Pro subscription.
