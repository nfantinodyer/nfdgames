One-line description

Tagline Send files between any device. Instantly.

Short description (≈30 words)

Short blurb OpenDrop is a free, cross-platform AirDrop alternative. Transfer files between iPhone, Android, PC, and Linux over Wi-Fi, Bluetooth, or the cloud, end-to-end encrypted, no internet required on a local network.

Long description (≈80 words)

Long blurb OpenDrop is a self-hosted, cross-platform file-transfer system. The mobile and desktop apps discover each other automatically over Wi-Fi using multicast DNS, connect directly peer-to-peer across networks when they're apart, fall back to Bluetooth LE for nearby transfers without a shared network, and stream through OpenDrop's own high-speed, redundant relay (Fly.io with automatic failover to Oracle Cloud) for remote transfers when a direct connection isn't available. File contents are end-to-end encrypted on the sending device with ChaCha20-Poly1305 and keyed to your account's shared secret, even our infrastructure can't read them. There are no ads, no third-party analytics SDKs in the apps, and the business is funded by an optional OpenDrop Pro subscription.
