  2. Description of the Service

    OpenDrop is a self-hosted, distributed file access system that helps you transfer and access files between your own devices (for example, between a mobile device and a personal desktop server). OpenDrop may use direct peer-to-peer connections, a secure relay, and authentication services to help your devices discover and connect to each other when they are not on the same network.

    OpenDrop is designed so your files remain on your devices. File contents are end-to-end encrypted in transit on every transfer path, including Wi-Fi / LAN, direct peer-to-peer connections, our own WebSocket relay, and Bluetooth Low Energy (between phones, with OpenDrop Pro), using ChaCha20-Poly1305 IETF AEAD (RFC 8439) with keys derived via HKDF-SHA256 from the secret your devices share when you pair them. Our relay servers carry file contents only in encrypted form, but they can see file names, folder names, file sizes and device names, which they need to route transfers. With OpenDrop Pro, our account service also stores the shared secret so your signed-in devices can connect to each other. The v1.0 app release (mobile and desktop) advertises protocol version 2 of the OpenDrop wire format, which makes end-to-end encryption mandatory: the v1.0 client and server refuse to send or accept unencrypted file bodies. Pre-1.0 clients running protocol version 0 or 1 (which predate end-to-end encryption) must update before they can transfer files. The Service facilitates transfer and access and does not provide general-purpose cloud storage for your files.
