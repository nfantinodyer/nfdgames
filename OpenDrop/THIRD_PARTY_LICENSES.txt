OpenDrop's peer-to-peer file-transfer feature is built on WebRTC. On the
desktop it uses the aiortc library; on mobile it uses flutter_webrtc. OpenDrop
uses the WebRTC DATA CHANNEL only — it transfers file bytes and never captures,
encodes, decodes, records, or transmits audio or video.

IMPORTANT — THE P2P/WebRTC STACK SHIPS NO PyAV AND NO FFmpeg; OPENDROP SHIPS NO GPL CODE.
The aiortc library depends on the PyAV ("av") package for media codecs. Because
OpenDrop never uses media, our release builds REPLACE the real "av" package with
a tiny pure-Python stub (see scripts/av_stub/ and scripts/install_av_stub.py) at
build time, immediately before compilation. The stub provides only the
import-time symbols aiortc needs and raises an error if any media code path is
ever exercised. As a result, no PyAV code — and no FFmpeg pulled in by the
WebRTC stack — is present in any shipped OpenDrop binary, and the entire
P2P/WebRTC stack listed below is permissively licensed (BSD-3-Clause, MIT,
Apache-2.0, ISC) with NO LGPL or GPL components. The av-stub itself is original
OpenDrop code distributed under OpenDrop's own license.

SEPARATELY from that permissive P2P stack, the DESKTOP build bundles two
components offered under the GNU Lesser General Public License v3 (LGPLv3).
OpenDrop elects the LGPLv3 option for both, links them dynamically, and ships
NO GPL-licensed application code anywhere:

  1. Qt for Python (PySide6) — the GUI toolkit the desktop app is built on. The
     Qt/PySide6 shared libraries ship as separate, individually replaceable
     files (.dylib/.dll/.so) loaded at run time; OpenDrop is NOT statically
     linked against Qt. See the dedicated "Qt for Python (PySide6)" section at
     the end of this file for versions and the written offer of source code.

  2. FFmpeg — a standalone, separately built, LGPL-clean FFmpeg *binary* used
     only for the file-conversion feature. It is a self-contained executable (no
     OpenDrop code is linked against it, and it shares no code with the WebRTC
     stack described here), and it ships with its own ffmpeg-LICENSE.txt, which
     governs it.

The complete LGPLv3 and GPLv3 license texts that govern Qt for Python (PySide6)
travel alongside this file as LICENSE.LGPLv3.txt and LICENSE.GPLv3.txt. OpenDrop
ships NO GPL-licensed code anywhere.

The DESKTOP app's interface also ships icon glyphs from the Lucide icon set
(package lucide-static v0.563.0, ISC; its portions derived from Feather are
MIT). They are SVG files under opendropserver/icons/, each opening with the
line "@license lucide-static v0.563.0 - ISC". Lucide's complete copyright and
